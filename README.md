# 💡 TECNOSOLUCIONES
## Proyecto: Luz automática con sensor de movimiento

### 1. Presentación del proyecto

Nuestro proyecto consiste en crear un sistema automático de iluminación utilizando Arduino y un sensor de movimiento PIR.

El objetivo es que una luz se encienda cuando detecte movimiento y se apague cuando no haya movimiento durante un determinado tiempo.

Buscamos ofrecer una solución práctica que ayude a evitar el consumo innecesario de electricidad.

### 5. Funcionamiento del producto

1. El sensor PIR detecta movimiento.
2. Envía una señal digital al Arduino.
3. Arduino procesa la información.
4. Si detecta movimiento, enciende el LED.
5. Si no detecta movimiento, apaga el LED.
